# Karina Spieker | SPA & Massoterapia

Landing page responsiva em português do Brasil para o espaço de SPA e massoterapia em Joinville.

## Conteúdo

- `dist/index.html`: página publicada
- `dist/style.css`: identidade visual e responsividade
- `dist/app.js`: WhatsApp, avaliações e interações
- `dist/assets/hero.png`: imagem hero ilustrativa

Site: https://karina-spieker-spa-joinville.leafyart2.chatgpt.site
